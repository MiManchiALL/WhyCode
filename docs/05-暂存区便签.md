## 待验证

- 重启 dev 后，在实际模型与 SSH 会话验收后台任务菜单的手动停止：行内二次确认后显示“用户主动停止”，模型运行中接收通知、空闲时续轮，且不切换用户正在查看的会话；关闭菜单与切换会话不取消已提交的停止。手动停止与命令自然完成唤醒空闲模型时，计时与心形等待动画应一起出现，首个输出后沿用正常反馈规则。模型调用 StopCommand 仍显示“模型主动停止：原因”或“模型主动停止”，切换会话及重启后保留；前台命令的用户停止与应用关闭也应识别实际来源。自动化覆盖生命周期、通知与持久恢复，隔离 Electron 覆盖行内确认、失败重试、键盘和窄窗口；实际模型与 SSH 端点仍需客户端验收。
- 在实际 SSH 终端中验收 Ctrl+V 粘贴中文和多行文本，以及方向键移入文字时块光标内字符的可读性；Bash 粘贴区域保留原生高亮。隔离 Electron 已验证键盘、剪贴板、输入路由与光标配色，未连接真实服务器。
- 重启 dev 后验收通用设置的内置浏览器清理：轻量清理后实际网站仍保持登录，全部清理关闭各会话的浏览器标签并退出网站登录；清理中离开、重开设置能显示进度。隔离 Electron 验证不使用用户的真实浏览器数据。
- 重启 dev 后验收实际会话的路径引用：从本地和 SSH 文件树右键引用或拖入输入框，检查草稿切换与重启恢复、排队和失败恢复、实际输入法组字及模型按路径读取，并确认紧凑菜单、文件图标及气泡内的标签辨识度。原 textarea 无法展示行内节点，因此新增 `lexical`/`@lexical/react`；已有 Dropdown Menu 不提供指针定位的上下文菜单，因此新增 `@radix-ui/react-context-menu`，职责见文档二 §12.3、§12.5。Electron 隔离界面已覆盖基本输入、剪贴板与附件、撤销、发送、斜杠菜单、草稿、会话隔离及窄窗口；真实 SSH 工具执行仍需客户端验收。
- 重启 dev 后验收右侧栏内置浏览器：实际网站的登录、弹窗链接、下载、视频全屏，以及窄窗口下的地址栏和查找；同一会话切换标签或收起侧栏应保留交互状态，切换会话后重新打开网页。需要设备权限或特殊弹窗流程的网站可从菜单转到系统浏览器。
- 重启 dev 后验收浏览器地址栏的本机 file 地址与 Windows 路径、data 临时页和 about:blank；使用实际本地 HTML 检查相对资源与导航。data 页重启不恢复；SSH 会话中的本机地址仍指向这台电脑，原有文件预览入口不变。
- 验收实际本地与 SSH 文件删除后的预览交互：删除时保留已加载内容，切换模式、换行或定位时浮层提示；快照的“打开当前文件”直接进入当前文件标签，缺失原因显示在内容区；主动刷新进入缺失页面并收起模式按钮，文件重建后刷新可恢复。
- 重启 dev 后在新模型回答中验收 Present 的调用范围：没有成品时不调用，同一回答需要撤回已声明成品时才提交空数组；删除文件不需要处理其它回答的成品声明。
- 客户端验收文件操作入口：普通会话的文件预览（宽栏按钮与窄栏菜单）和成品卡片菜单不显示保存到本机；SSH 会话保留保存入口，普通会话的默认应用打开与文件夹定位正常。
- 重启 dev 后，在新建的实际模型会话中验收计划自动推进：创建即显示首项进行中，完成一项后下一项同步进入进行中，模型不再额外调用启动；中途调整顺序、停止后恢复和最终验证沿用同一计划状态。
- 在新的实际模型回合中验收 PPT 读取与创建流程：读取未知文档按 nextOffset 分页，自定义脚本使用 NODE RUN，明确的生成要求才使用数量与内容断言；观察参数出错后模型能否按反馈修正。需重启 dev，已有 SSH 连接先同步新版 Skill。
- 在实际视觉模型会话中验收同一步读取 5～10 张 Office 页图，以及按任务选择拼图分组、识别来源和继续查看细节；超过十张时模型收到数量提示，可在后续步骤继续。覆盖本地与 SSH 文件来源，已有远端连接须先“同步/更新 Skill”以取得新版指引。
- 实际客户端验收批量二进制文件删除与文件回滚的响应、内存和权限审批。使用新建的测试文件；原崩溃会话的删除已开始且未正常收尾，需先核实剩余文件再决定是否继续。
- 实际 SSH 会话主动断开、清理组件或重启后，确认输入仍可编辑，发送按钮禁用，Enter/Ctrl+Enter 不闪出消息、不新增“已处理 0m 0s”；重新连接后发送、即时计时和思考动画正常。
- 用实际业务文件验收 Office 的中文字体、复杂模板与图表排版；自动化用例不覆盖这些视觉保真问题。ARM64 与 macOS 运行环境尚未实机验证。
