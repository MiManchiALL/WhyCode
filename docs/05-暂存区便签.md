## 坑与备忘

- **WebSearch P0 边界（2026-07-19～21 完整链路客户端验收并合并；2026-07-23 Tavily 扩展）**：统一工具名和模型 schema 不暴露搜索后端；Core 只定义 `WebSearchHandler`，Main 每次调用读取活动后端和对应加密 key，因此切换、改 key 或调整 Tavily 质量档位都不重建 schema。`query` 默认单个最多 500 字符，也可为 2～4 个去重查询，`max_results` 每查询默认 5/最多 10、总结果封顶 20。Perplexity 数组只产生一次 multi-query 请求，并兼容官方分组/SDK 扁平两种明确响应；Tavily 官方只接收字符串，故在同一工具调用内有界并发。Tavily 只提供 basic/advanced 两档并默认 basic；开启自动参数选择 general/news/finance 主题，同时显式固定深度、结果数、筛选条件和内容边界，避免服务端暗改成本。结果按 Tavily score 作同批相对排序，不设跨主题硬阈值；Core 再对两家统一执行规范化 URL 去重和总量裁剪。批量普通失败保留成功结果并明确列出失败查询，全部失败、用户取消或统一超时才整体报错。结果只保留有界标题、HTTP(S) URL、摘要和日期，并生成 `[Sx]` Markdown 来源；详细事实继续 WebFetch。首次隐私审批与所有工具共用会话级判定尾链；普通搜索错误随本步全部结果稳定提交后回流模型。Main 以 Electron `net.fetch` 使用 Chromium 网络栈和系统代理，两家共用固定端点、超时、禁止重定向、累计响应上限与脱敏错误；聊天里出现过的 key 不得自动搬入本机配置。服务端 answer/raw content/images、自动后端回退和多后端聚合仍不开放，避免第二模型回答或第二套结果流。
