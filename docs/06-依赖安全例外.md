# 依赖安全例外

`pnpm audit --prod` 默认只允许本文件列出的精确 GHSA 例外。新增或续期例外前必须确认依赖链、实际可达性、可用修复版本和移除条件，不能按包名或严重级别整体忽略。

## `image-size` 经 `pptxgenjs` 引入的无限循环拒绝服务

- GHSA：`GHSA-w3rx-r6r6-pgpr`、`GHSA-5p2g-fcmc-qvqq`
- 依赖链：`@whycode/desktop > pptxgenjs@4.0.1 > image-size@1.2.1`
- 决策日期：2026-09-03
- 下次复查：2026-10-03
- 状态：临时接受并由 `pnpm-workspace.yaml` 精确忽略

接受理由：

1. 两个公告影响 `image-size <= 2.0.2` 的 ICNS、JXL 和 HEIF 解析器，但截至决策日期，npm 最新版本仍为 `2.0.2`，没有可安装的安全版本。
2. `pptxgenjs@4.0.1` 虽然声明了 `image-size`，其发布的 `dist` 代码没有导入或调用该包；唯一相关的 `getSizeFromImage` 代码被完整注释并标记为未使用。因此 WhyCode 的 Office 构建链不会进入受影响解析器。
3. 强行跨主版本覆盖不存在的修复版本无法降低风险，反而会破坏可复现安装。

满足任一条件时立即移除例外并更新锁文件：

- `image-size` 发布不受这两个公告影响的版本；
- PptxGenJS 发布移除该无效依赖的版本；
- WhyCode 或上游开始实际导入 `image-size`；
- Office 资产处理链出现能够调用受影响解析器的新路径。

续期时必须重新检查 npm 已发布版本、PptxGenJS 发布包中的实际引用和 `pnpm audit --prod` 输出，并更新决策日期与下次复查日期。
