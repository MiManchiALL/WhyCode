# 依赖安全例外

依赖审计不按包名或严重级别整体忽略。新增例外前必须确认精确公告、依赖链、实际可达性、可用修复版本、复查时间和移除条件。

当前无接受的安全例外。桌面依赖使用 `pnpm audit --prod`；独立 Office 运行环境在 `workspace-runtime/office` 内执行 `npm audit --omit=dev`。该环境的锁文件通过精确 overrides 使用已修复的 fflate 与 image-size，升级 LibreOffice Kit 或 PptxGenJS 时同步复核是否仍需覆盖，并执行生成、渲染和重算测试。

工作区 `overrides` 将 DOMPurify、body-parser、fast-uri、ip-address 和 undici 限定到已修复版本，Zod 的直接依赖下限同步覆盖集合校验的内存耗尽修复；它们不是审计忽略。更新这些约束时核查上游版本范围，并验证 Markdown/图表净化、MCP 配置与传输、模型工具 schema 和网页网络边界；上游下限包含修复后移除不再必要的覆盖。

MCP SDK 使用已修复 [HTTP/OAuth 跨源重定向泄露](https://github.com/modelcontextprotocol/typescript-sdk/security/advisories/GHSA-6prh-2h8m-c8cw)的版本。根目录 `pnpm-workspace.yaml` 将其 Hono 与 Node 适配器锁定到已修复静态路径重复解码的版本（[Hono 公告](https://github.com/honojs/hono/security/advisories/GHSA-5r4p-p66f-jhc7)、[Node 适配器公告](https://github.com/honojs/node-server/security/advisories/GHSA-rmxm-3fg6-px4f)）。升级 SDK 时复核其依赖下限；覆盖不再需要时移除，并验证 MCP stdio/HTTP 连接及 OAuth 发现、注册和令牌刷新。

KaTeX 的部分上游依赖仍限定旧版本范围，根目录 `pnpm-workspace.yaml` 因此统一覆盖到已修复[原型污染导致信任限制绕过](https://github.com/KaTeX/KaTeX/security/advisories/GHSA-238p-pmpm-9mq7)的版本，保证数学渲染与 CSS 使用同一版本。更新该覆盖时验证 Streamdown、行内与块级公式、矩阵和错误公式；上游版本范围覆盖修复版本后移除对应覆盖。此项用于安装修复版本，不属于审计忽略。
